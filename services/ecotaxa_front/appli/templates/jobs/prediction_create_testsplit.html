PREDICTION: Held-out test evaluation

{{ filters_info|safe }}

Before the classifier is used for real, you can set aside a percentage of the Learning Set to check how accurate it actually is — per taxon and overall — on data it wasn't trained on.

  • A stratified sample (i.e. the same percentage from each category) is held out, a classifier is trained on the rest and tested against it; its accuracy is reported below once the job finishes, and kept here as part of this project's performance history.
  • The classifier actually deployed to classify your target project's objects is always trained on the full Learning Set, regardless of this setting — held-out evaluation only affects the reported numbers, never what gets trained for real.
  • 0% is a valid choice: nothing is held out, the full Learning Set is used to train, and no accuracy is evaluated or recorded for this run.
